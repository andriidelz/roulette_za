Доступные макросы

Макросы вставляются в текст в формате {имя_макроса} и автоматически заменяются при отправке уведомления.

Глобальные макросы, доступные во всех типах уведомлений:
Макрос Описание Пример
{daily_bets_limit} Лимит ставок за день 2880
{daily_bets_zero_limit} Лимит ставок для Zero 100
{minimum_withdrawal} Минимальная сумма для вывода 10.00
{prize_fund} Сумма недельного призового фонда 1000.00
{prize_top} Количество призовых мест 100
Макросы для уведомлений типа balance_updated:
Макрос Описание Пример
{amount} Сумма пополнения 50.00
{balance} Текущий баланс пользователя 150.00
Макросы для уведомлений типа top_rating_entered:
Макрос Описание Пример
{position} Позиция пользователя в рейтинге 5
{points} Количество очков пользователя 120
