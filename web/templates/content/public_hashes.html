Как работает проверка

Перед каждым раундом система генерирует случайное число и криптографическую соль, затем вычисляет хеш SHA-256.

Хеш публикуется до начала раунда, а число и соль раскрываются после его завершения.

Вы можете самостоятельно проверить, соответствует ли опубликованный хеш открытым данным:

SHA-256(число:соль)
Пример проверки:
  1. Номер: 5
  2. Соль: a1b2c3d4e5f6
  3. Хеш: e37f...0840

Для проверки вычислите SHA-256 хеш от строки 5:a1b2c3d4e5f6 и сравните с оригинальным хешем. Если они совпадают, результат честный.

Как работает система честной игры
Генерация хеша

Перед началом раунда система генерирует случайное число от 0 до 36 и уникальную криптографическую соль. Затем вычисляется SHA-256 хеш от строки "число:соль".

Публикация хеша

Хеш публикуется до того, как игроки начинают делать ставки. Это гарантирует, что результат предопределен и не может быть изменен после размещения ставок.

Раскрытие результата

После завершения раунда система раскрывает использованное число и соль. Любой может проверить, соответствует ли опубликованный заранее хеш этим данным.

Пример самостоятельной проверки (на языке Go):
package main

import (
    "crypto/sha256"
    "encoding/hex"
    "fmt"
)

func main() {
    number := 5                   // Число, которое выпало
    salt := "a1b2c3d4e5f6"        // Соль из сообщения бота
    originalHash := "e37f...0840" // Хеш из начала раунда
    
    // Формируем строку и вычисляем хеш
    data := fmt.Sprintf("%d:%s", number, salt)
    hasher := sha256.New()
    hasher.Write([]byte(data))
    computedHash := hex.EncodeToString(hasher.Sum(nil))
    
    // Проверяем совпадение
    if computedHash == originalHash {
        fmt.Println("Результат верен!")
    } else {
        fmt.Println("Результат не соответствует хешу!")
    }
}

Благодаря системе предварительного хеширования, результат каждого раунда определяется заранее и не может быть изменен после начала приема ставок. Хеш публикуется до начала раунда, а после завершения вы можете проверить его соответствие с открытыми данными.

Криптографический алгоритм SHA-256 математически гарантирует, что невозможно подобрать другую комбинацию номера и соли, которая дала бы такой же хеш.

Соль — это случайная строка символов, которая добавляется к числу перед вычислением хеша. Она нужна для того, чтобы нельзя было заранее подготовить таблицу соответствия всех возможных чисел (от 0 до 36) их хешам.

Без соли злоумышленник мог бы просто посмотреть в такую таблицу и узнать, какое число выпадет. Соль добавляет непредсказуемость и гарантирует уникальность хеша для каждого раунда, даже если выпадают одинаковые числа.

Вы можете использовать:

  • Встроенную форму проверки на этой странице
  • Онлайн-калькуляторы SHA-256 (например, Online SHA-256)
  • Командную строку на Linux/Mac: echo -n "5:a1b2c3d4e5f6" | sha256sum
  • Любой язык программирования с библиотекой для вычисления SHA-256 хешей

Не забудьте использовать формат число:соль без пробелов и других символов.
