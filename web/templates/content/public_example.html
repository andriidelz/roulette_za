Пример проверки хеша SHA-256

На этой странице вы можете увидеть пример реализации алгоритма проверки хеша SHA-256 с использованием JavaScript. Вы можете использовать этот код для самостоятельной проверки результатов нашей рулетки.

Код для проверки хеша
// Функция для проверки хеша SHA-256
async function verifyHash(number, salt, originalHash) {
    try {
        // Формируем строку в формате "число:соль"
        const data = `${number}:${salt}`;
        
        // Кодируем строку в массив байтов
        const encoder = new TextEncoder();
        const dataBuffer = encoder.encode(data);
        
        // Вычисляем SHA-256 хеш
        const hashBuffer = await crypto.subtle.digest('SHA-256', dataBuffer);
        
        // Преобразуем ArrayBuffer в строку hex
        const hashArray = Array.from(new Uint8Array(hashBuffer));
        const computedHash = hashArray.map(b => 
            b.toString(16).padStart(2, '0')
        ).join('');
        
        // Проверяем, совпадает ли вычисленный хеш с оригинальным
        const isValid = computedHash === originalHash;
        
        return {
            isValid,
            computedHash,
            originalHash,
            number,
            salt,
            input: data
        };
    } catch (error) {
        console.error('Ошибка при проверке хеша:', error);
        return {
            isValid: false,
            error: error.message
        };
    }
}
Как использовать этот код:
  1. Скопируйте код функции verifyHash
  2. Добавьте его в свой JavaScript-проект
  3. Вызовите функцию с параметрами: число, соль и оригинальный хеш
  4. Функция вернет объект с результатом проверки и дополнительной информацией
Обратите внимание: Этот код использует Web Crypto API, который доступен в большинстве современных браузеров.

Как работает проверка хеша?

Генерация данных

Система создает строку в формате "число:соль" (например, "5:a1b2c3d4e5f6"). Здесь число — это результат раунда рулетки (от 0 до 36), а соль — случайная строка символов.

Вычисление хеша

Эта строка преобразуется в массив байтов, к которому применяется алгоритм SHA-256. Результатом является 64-символьная строка в шестнадцатеричном формате.

Публикация и проверка

Перед началом раунда публикуется только хеш. После завершения раунда раскрываются число и соль. Вы можете самостоятельно вычислить хеш и убедиться, что он соответствует опубликованному.

Почему это гарантирует честность?

Поскольку хеш публикуется до начала приема ставок, а результат и соль раскрываются после окончания раунда, система не может изменить результат после того, как игроки сделали свои ставки. Криптографический алгоритм SHA-256 гарантирует, что невозможно найти другую пару "число:соль", которая дала бы такой же хеш.
