# Автоматическое распределение призов в системе рулетки

## Обзор системы

Система автоматически распределяет еженедельные призовые фонды на основе рейтинга игроков, сформированного за предыдущую неделю. Призы зачисляются на баланс пользователей, занявших призовые места.

## Настройка расписания распределения

Распределение призов настраивается через панель администратора с помощью двух ключевых параметров:

### 1. День недели распределения (`prize_distribution_day`)

| Значение | День недели |
|----------|-------------|
| 1        | Понедельник (по умолчанию) |
| 2        | Вторник     |
| 3        | Среда       |
| 4        | Четверг     |
| 5        | Пятница     |
| 6        | Суббота     |
| 7        | Воскресенье |

### 2. Время распределения (`prize_distribution_time`)

Время указывается в формате ЧЧ:ММ по UTC+0.  
Примеры: `00:10`, `12:00`, `23:30`

## Настройка призового фонда

Призовой фонд настраивается через следующие параметры:

### 1. Размер призового фонда (`weekly_prize_amount`)

Сумма, которая будет распределена между победителями (в долларах).  
По умолчанию: 1000$

### 2. Количество призовых мест (`weekly_prize_top`)

Количество игроков, которые получат призы.  
По умолчанию: 100

## Механизм распределения

### Расчетный период

Система всегда распределяет призы за **предыдущую полностью завершенную неделю**:
- Неделя считается с понедельника (00:00) по воскресенье (23:59)
- Распределение выполняется только после завершения недели

### Алгоритм распределения

1. В указанный день недели и время система запускает процесс распределения
2. Система определяет топ-игроков за предыдущую неделю согласно настройке `weekly_prize_top`
3. Призовой фонд распределяется между игроками пропорционально набранным баллам
4. Вычисляется приз для каждого игрока по формуле:  
   `Приз = (Баллы игрока / Общее количество баллов) * Призовой фонд`
5. Средства зачисляются на баланс пользователей
6. Пользователи получают уведомление о полученном призе

### Защитные механизмы

- Распределение не запускается чаще, чем раз в 23 часа
- Распределение запускается в течение 5 минут после указанного времени
- Система отмечает призовой фонд как "обработанный" после успешного распределения
- В админ-панели отображается статус распределения

## Примеры работы

### Пример 1: Распределение в понедельник

**Настройки:**
- День распределения: Понедельник (`prize_distribution_day` = 1)
- Время распределения: 00:10 (`prize_distribution_time` = "00:10")

**Процесс:**
1. Неделя с 1 по 7 мая (пн-вс): игроки делают ставки и зарабатывают баллы
2. Неделя заканчивается в воскресенье 7 мая в 23:59
3. В понедельник 8 мая в 00:10 система запускает распределение призов
4. Призы распределяются за предыдущую неделю (1-7 мая)

### Пример 2: Распределение в четверг

**Настройки:**
- День распределения: Четверг (`prize_distribution_day` = 4)
- Время распределения: 12:00 (`prize_distribution_time` = "12:00")

**Процесс:**
1. Неделя с 1 по 7 мая (пн-вс): игроки делают ставки и зарабатывают баллы
2. Неделя заканчивается в воскресенье 7 мая в 23:59
3. В четверг 11 мая в 12:00 система запускает распределение призов
4. Призы распределяются за предыдущую неделю (1-7 мая)

## Ручное управление распределением

### Администраторские функции

Через админ-панель можно выполнить следующие действия:

1. **Просмотр рейтингов** - список всех недельных рейтингов с информацией о призовом фонде и статусе распределения

2. **Ручное распределение призов** - возможность вручную запустить распределение призов за выбранную неделю (только для завершенных недель)

3. **Отмена распределения** - возможность отменить ошибочно выполненное распределение (система вернет средства с балансов пользователей)

4. **Изменение параметров** - возможность изменить размер призового фонда и количество призовых мест

## Устранение неполадок

В случае проблем с распределением призов:

1. Проверьте настройки `prize_distribution_day` и `prize_distribution_time`
2. Убедитесь, что неделя полностью завершена
3. Проверьте статус предыдущего распределения в админ-панели
4. Если необходимо, используйте функцию отмены распределения и запустите его заново
