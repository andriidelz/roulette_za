# Телеграм-бот Рулетка (MVP)

Телеграм-бот для социального казино на основе упрощенного принципа игры в рулетку.
Пользователи могут делать ставки на красное, черное или зеро, соревноваться в рейтинге и получать призы.

## Особенности

- Упрощенная игра в рулетку (красное/черное/зеро)
- Еженедельный рейтинг игроков
- Супер-рейтинг (на основе позиций в еженедельных рейтингах)
- Распределение призового фонда
- Система локализации (украинский, английский и русский языки)
- Админ-панель для управления проектом
- Криптографически безопасная система проверки честности результатов

## Установка и запуск

### Локальный запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/your-username/roulette-bot.git
   cd roulette-bot
   ```

2. Инициализируйте проект:

   ```bash
   make init
   ```

3. Отредактируйте файл `.env` и добавьте свой Telegram Bot Token:

   ```
   TELEGRAM_TOKEN=your_token_here
   ```

4. Создайте базу данных и выполните миграции:

   ```bash
   make migrate
   ```

5. Запустите бота и админ-панель:

   ```bash
   make run
   ```

### Запуск через Docker

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/your-username/roulette-bot.git
   cd roulette-bot
   ```

2. Создайте файл `.env` с вашим Telegram Bot Token:

   ```
   TELEGRAM_TOKEN=your_token_here
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=secure_password
   SESSION_SECRET=your_secret_key
   ```

3. Запустите через Docker Compose:

   ```bash
   docker-compose up -d
   ```

4. Админ-панель будет доступна по адресу: <http://localhost:8080>

## Безопасность и честная игра

Для обеспечения честности игры используется система предварительного хеширования результатов:

1. Перед началом раунда генерируется случайное число от 0 до 36
2. Число хешируется вместе с криптографической солью
3. Хеш публикуется в начале раунда
4. После окончания раунда, число и соль раскрываются
5. Пользователи могут проверить, что хеш соответствует раскрытому числу и соли

Таким образом гарантируется, что результат не может быть изменен после начала раунда, а при этом остается непредсказуемым для игроков до его завершения.

Администраторы могут проверить валидность любого результата через админ-панель в разделе "Rounds/Hashes".

## Проверка честности игры

Каждый раунд рулетки можно проверить для подтверждения честности результатов. Система использует криптографически безопасный механизм предварительного раскрытия хеша:

1. В начале раунда бот показывает хеш результата
2. После завершения раунда, бот раскрывает число и соль, использованные для генерации хеша
3. Пользователь может самостоятельно проверить, что хеш соответствует раскрытым данным

### Как проверить результат

Для проверки результата:

1. Возьмите число и соль, предоставленные ботом после завершения раунда
2. Сформируйте строку в формате: `[число]:[соль]` (например, `5:a1b2c3d4e5f6`)
3. Вычислите SHA-256 хеш от этой строки
4. Сравните полученный хеш с хешем, который был предоставлен в начале раунда

Если хеши совпадают, результат честный.

### Пример проверки (Go)

```go
package main

import (
    "crypto/sha256"
    "encoding/hex"
    "fmt"
)

func main() {
    number := 5                  // Число, которое выпало
    salt := "a1b2c3d4e5f6"       // Соль из сообщения бота
    originalHash := "e37f...0840" // Хеш из начала раунда
    
    // Формируем строку и вычисляем хеш
    data := fmt.Sprintf("%d:%s", number, salt)
    hasher := sha256.New()
    hasher.Write([]byte(data))
    computedHash := hex.EncodeToString(hasher.Sum(nil))
    
    // Проверяем совпадение
    if computedHash == originalHash {
        fmt.Println("Результат верен!")
    } else {
        fmt.Println("Результат не соответствует хешу!")
    }
}
```
