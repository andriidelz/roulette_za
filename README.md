# Телеграм-бот Рулетка (MVP)

Телеграм-бот для социального казино на основе упрощенного принципа игры в рулетку.
Пользователи могут делать ставки на красное, черное или зеро, соревноваться в рейтинге и получать призы.

## Особенности

- Упрощенная игра в рулетку (красное/черное/зеро)
- Еженедельный рейтинг игроков
- Супер-рейтинг (на основе позиций в еженедельных рейтингах)
- Распределение призового фонда
- Система локализации (украинский, английский и русский языки)
- Админ-панель для управления проектом

## Установка и запуск

### Локальный запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/your-username/roulette-bot.git
   cd roulette-bot
   ```

2. Инициализируйте проект:

   ```bash
   make init
   ```

3. Отредактируйте файл `.env` и добавьте свой Telegram Bot Token:

   ```
   TELEGRAM_TOKEN=your_token_here
   ```

4. Создайте базу данных и выполните миграции:

   ```bash
   make migrate
   ```

5. Запустите бота и админ-панель:

   ```bash
   make run
   ```

### Запуск через Docker

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/your-username/roulette-bot.git
   cd roulette-bot
   ```

2. Создайте файл `.env` с вашим Telegram Bot Token:

   ```
   TELEGRAM_TOKEN=your_token_here
   ADMIN_USERNAME=admin
   ADMIN_PASSWORD=secure_password
   SESSION_SECRET=your_secret_key
   ```

3. Запустите через Docker Compose:

   ```bash
   docker-compose up -d
   ```

4. Админ-панель будет доступна по адресу: <http://localhost:8080>

## Использование

### Команды бота

- `/start` - Начало работы с ботом
- `/play` - Начать игру
- `/profile` - Просмотреть профиль
- `/stats` - Просмотреть статистику
- `/rating` - Просмотреть еженедельный рейтинг
- `/superrating` - Просмотреть супер-рейтинг
- `/balance` - Просмотреть баланс
- `/withdraw` - Вывести средства
- `/faq` - Частые вопросы

### Админ-панель

- Управление пользователями
- Просмотр статистики
- Управление рейтингами
- Настройка призовых фондов
- Управление локализациями
- Обработка запросов на вывод средств
- Проверка хешей рулетки

## Безопасность и честная игра

Для обеспечения честности игры используется система хеширования результатов. Каждый результат игры (число от 0 до 36) генерируется заранее с использованием криптографической соли, что обеспечивает невозможность предсказания или подделки результатов.

Администраторы могут проверить валидность любого результата через админ-панель в разделе "Roulette Hashes".
